# C盘清理大师 - 专业版

> 一款功能强大的 Windows 系统垃圾清理工具，对标 Dism++、CCleaner、火绒垃圾清理等专业工具。

## 功能特点

### 🧹 16 大清理模块
| 模块 | 说明 |
|------|------|
| **Windows 临时文件** | 扫描系统临时目录中的 `.tmp`、`.log`、`.bak` 等文件 |
| **回收站清理** | 清空 `$Recycle.Bin` 回收站 |
| **浏览器缓存** | 清理 Chrome / Edge / Firefox 浏览器缓存 |
| **系统日志** | 清理 Windows Logs / Debug 目录的 `.log`、`.etl` 文件 |
| **Windows 更新缓存** | 清理 `SoftwareDistribution/Download` 更新下载缓存 |
| **预读文件 (Prefetch)** | 清理 `*.pf` 预读文件 |
| **缩略图缓存** | 清理 `Thumbs.db` 缩略图数据库 |
| **字体缓存** | 清理字体缓存文件 |
| **错误报告** | 清理 Windows Error Reporting (WER) 存档 |
| **传递优化缓存** | 清理 Delivery Optimization 下载缓存 |
| **Office 缓存** | 清理 Office 文档缓存 |
| **.NET 缓存** | 清理 .NET Framework 程序集缓存 |
| **DNS 缓存** | 清理 DNS 解析缓存 |
| **剪贴板历史** | 清理剪贴板历史记录 |
| **跳转列表** | 清理任务栏跳转列表 |
| **最近文档** | 清理最近打开的文件记录 |

### 🖥️ 现代图形界面
- 分类展示清理项，支持按模块勾选
- 实时扫描进度与详情查看
- 清理前后空间对比
- 管理员权限自动检测与提权
- 深色/浅色主题支持

### ⚡ 高性能引擎
- 多线程并发扫描，充分利用 CPU
- 智能文件大小统计与格式化显示
- 安全清理机制，避免误删系统文件
- 支持扫描中断与清理中断

## 安装与运行

### 环境要求
- **操作系统**: Windows 7 / 8 / 10 / 11
- **Python**: 3.8 或更高版本
- **权限**: 建议以管理员身份运行（可获得最佳清理效果）

### 快速启动

```bash
# 1. 克隆或下载项目
git clone https://github.com/your-repo/c-cleaner.git
cd c-cleaner

# 2. 直接运行（无需安装额外依赖，仅使用 Python 标准库）
python main.py
```

> **提示**: 本项目仅依赖 Python 标准库（`tkinter`、`os`、`shutil`、`threading` 等），无需 `pip install` 任何第三方包。

### 以管理员身份运行

**方法一：右键菜单**
1. 右键点击 `main.py`
2. 选择「以管理员身份运行」

**方法二：命令行**
```bash
# 以管理员身份打开 PowerShell 或 CMD，然后执行
python main.py
```

**方法三：程序内提权**
- 程序启动时会自动检测是否拥有管理员权限
- 如未以管理员运行，会弹出提示窗口，点击「以管理员身份运行」即可自动提权

## 使用说明

### 基本流程

1. **启动程序** — 运行 `python main.py`
2. **扫描系统** — 点击「开始扫描」按钮，程序将扫描所有 16 个清理模块
3. **查看结果** — 扫描完成后，各模块会显示可清理的文件数量和空间大小
4. **选择清理项** — 勾选需要清理的模块（默认全选）
5. **执行清理** — 点击「开始清理」按钮，程序将删除选中的垃圾文件
6. **查看结果** — 清理完成后显示释放的空间总量

### 注意事项

- ⚠️ 清理前请确认重要文件已备份
- ⚠️ 部分清理项（如系统日志、更新缓存）需要管理员权限
- ⚠️ 浏览器缓存清理会清除登录状态，需重新登录网站
- ⚠️ 清理回收站后文件无法恢复

## 技术栈

| 技术 | 用途 |
|------|------|
| **Python 3** | 核心开发语言 |
| **tkinter / ttk** | 图形界面框架 |
| **threading** | 多线程并发扫描 |
| **shutil / glob** | 文件系统操作 |
| **ctypes** | Windows API 调用（管理员权限检测） |
| **subprocess** | 系统命令执行（DNS 缓存清理等） |
| **dataclasses** | 数据结构定义 |
| **pathlib** | 现代化路径操作 |

> 零外部依赖，仅使用 Python 标准库。
